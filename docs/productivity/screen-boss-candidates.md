# BOSS 逐位筛查在线简历

[技能入口](../../skills/productivity/screen-boss-candidates/SKILL.md)

## 做什么

按用户提供的岗位要求和当前 BOSS直聘筛选条件，逐位读取在线简历，用可见的职业证据核验匹配程度。每次打开一位候选人的简历后停留，给出简短结论，供用户判断。

用户说“下一位”时，在相同条件下继续查看未看过的候选人。

## 什么时候使用

- 希望保持当前搜索条件，逐位查看在线简历。
- 需要确认候选人是否实际做过岗位要求的工作。
- 已查看当前人选，希望继续到下一位。

调用示例：

> 使用 $screen-boss-candidates，按我提供的岗位要求和当前筛选条件，打开一位符合条件的候选人在线简历，停留供我查看。

需要已登录的 BOSS直聘界面、岗位要求，以及当前环境可用的桌面或浏览器自动化工具。明确要求使用 App 时，需要工具能够操作该 App。

## 常见问题

**会修改已有筛选条件吗？**

不会自行放宽或替换条件。“下一位”沿用当前关键词、城市、学历、经验、排序等设置。用户新增的职业要求会纳入本轮核验。

**会自动联系候选人或下载简历吗？**

默认只读取和展示在线简历。发消息、索要或下载简历、收藏、标记及其他写入操作均需要用户明确要求。

**信息不足或结果耗尽时怎么办？**

没有可见证据的能力标为“未证实”。无法证实硬性条件时跳过；没有更多符合者时如实说明缺少的职业证据，保持原条件。

**如何保护隐私？**

公开技能只包含通用方法和匿名示例。候选人真实姓名、联系方式、简历内容、筛选历史、账号凭据、私人路径和公司内部信息不写入公开文件。对用户的反馈只保留判断匹配所需的职业证据。

## 完成标准

- 当前简历与所选候选人一致，且留在屏幕上供用户查看。
- 已核验用户强调的核心经验及职业硬性条件，指出明显缺口。
- 当前筛选条件保持一致，本轮未重复展示已看过的人选。
- 每次仅展示一位，停止操作并等待用户查看或继续。

无匹配人选时，说明结果已耗尽或缺少哪项职业证据，同样停止操作。
