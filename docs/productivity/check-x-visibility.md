# 检查 X 账号是否被限流

怀疑自己的帖子搜不到、回复被折叠，或推荐曝光突然下滑时，先提供账号名即可。已有回复链接、X 通知或 Analytics 导出时可以一起提供。

## 调用示例

> 使用 `$check-x-visibility` 检查 @账号名。最近几条原创在主页能看到，但别人说搜不到。

技能会先确认当前浏览器的身份：未登录访客、号主本人，还是无关的登录账号。访客能看的只有主页和帖子直链。「最新」搜索、账号建议和完整回复串需要一个没有关注该账号的登录账号来看，手头没有时会一次性说明需要哪几张截图。有逐帖数据时，比较相邻两个完整的四周，列出样本量和每帖曝光中位数。

## 如何读结果

- **无痕搜索跳到登录页怎么办？** 这一项会记为证据不足。独立登录账号在相同查询下看到的结果可以补上这一项。
- **标签报告是空的，说明现在没事吗？** 报告按自然月出，上个月的内容要到月底后约 10 天才更新，本月刚开始的限制还看不到。空报告只能说明已覆盖的那个月。
- **报告出现标签，能确定何时恢复吗？** 报告能说明指定时期哪个账号或帖子有标签。源码里的有效期描述某条规则的配置，恢复时间还需要当前状态佐证。
- **什么算检查完成？** 每个请求检查的入口都有实测结果或具体缺口，结论注明观察身份、时间和适用范围。如果只能证明曝光下降，会保留原因待定，并说明哪份材料最能帮助核实。
